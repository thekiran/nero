# Community code of conduct

Treat contributors, users and maintainers with respect. Discuss the code and the
problem, provide reproducible evidence, and welcome people with different levels
of experience and backgrounds.

Harassment, discriminatory abuse, threats, sexual attention, publishing another
person's private information and deliberately disruptive behavior are not
acceptable in issues, pull requests, discussions or project-related spaces.
Never include credentials or third-party personal data in reports.

Maintainers may edit or remove harmful content, close disruptive discussions and
restrict participation proportionately. Explain moderation decisions when doing
so is appropriate and does not expose private information. Apply these standards
to everyone, including maintainers.

Report concerns privately using a contact method published on the maintainer's
GitHub profile. If none is available, request a private channel without posting
personal details publicly. Security vulnerabilities follow [SECURITY.md](SECURITY.md).
